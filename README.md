This project is a personal portfolio website focused on performance, minimalism, and user experience. The entire application was built using only HTML, CSS, and Vanilla JavaScript, without frameworks, prioritizing clean structure, responsiveness, and refined visual design.

The goal of this project was to create a modern and professional experience inspired by premium digital products and SaaS interfaces.

✨ Main Features
🌍 Dynamic translation system (Portuguese, English, and Spanish)
🌙 Dark mode with LocalStorage persistence
🎬 Smooth reveal animations using Intersection Observer
🧭 Sticky navbar with smooth scrolling navigation
📱 Fully responsive layout
🖼️ Interactive hero section with grayscale-to-color image hover effect
🔗 Social media icons with brand-colored glow effects
🧠 “About Me” section structured into multiple readable paragraphs
⚙️ Interactive tech stack with custom hover animations
💼 Premium-style project cards with smooth transitions
📬 Modern and minimalist contact section
🎨 Refined UI inspired by modern SaaS and startup websites
🛠️ Technologies Used
HTML5
CSS3
JavaScript (Vanilla JS)
Font Awesome
